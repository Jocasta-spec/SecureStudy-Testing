# 32 Test Cases Bảo Mật – SecureStudy

**Mục tiêu**: Kiểm thử bảo mật không chỉ nhằm phát hiện lỗ hổng, mà còn chứng minh rằng các cơ chế bảo vệ đã triển khai (CSRF, JWT, RBAC, Prepared Statement, Rate-limiting…) hoạt động đúng và thực sự hiệu quả.

**Tổng cộng**: 32 test cases, chia thành 5 nhóm chính:

- CSRF Protection
- JWT & CRUD Security
- RBAC – Kiểm soát truy cập theo vai trò
- SQL Injection
- Rate-limiting – Giới hạn tần suất truy cập
